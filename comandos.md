# Git Local

1. Inicializar um repositório
git init

2. Verificar o estado
git status

3. Adicionar arquivos à área de staging
git add arquivo.txt
git add .

4. Conferir o que será commitado
git diff --staged

5. Criar o commit
git commit -m "Mensagem do commit"

6. Ver histórico de commits
git log
git log --oneline
