# Projeto Exemplo - Minicurso Git & GitHub

Este é o repositório de prática utilizado durante o **Minicurso de Git & GitHub**.

## 🚀 Como Usar
1. Clone este repositório: `git clone <URL-DO-REPOSITO>`
2. Navegue até a pasta: `cd minicurso-git-github-demo`
3. Crie uma branch para sua alteração: `git checkout -b feature/sua-branch`
